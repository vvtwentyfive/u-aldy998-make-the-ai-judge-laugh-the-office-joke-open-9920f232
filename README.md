The brief asks for a single-line office joke, at most 200 characters.

## The entry

> IT fixed the office printer: it no longer jams — it just emails the whole office a 40-page report explaining why it jammed.

## How the program works

`main.ts` runs on Node 22 using only the standard library, with no network access at all. It writes the joke to `/output/entry.txt`. Because there is no randomness and no outside input, the file it produces is identical on every run.
